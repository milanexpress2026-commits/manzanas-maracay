# Confirmaciones comerciales para producción

Las reglas siguientes proceden del encargo de fase 4. **No constituyen datos cargados en la base nueva ni una confirmación automática de un empaque.** Los propietarios deben registrar su catálogo y confirmar cada configuración que utilizarán. Una cantidad desconocida se conserva pendiente; no se convierte en cero ni se deduce del calibre.

No se vende fruta por pieza suelta. Puedes confirmar un empaque limitado a caja cuando esa sea la única presentación conocida; no habilites medias o blíster hasta conocer sus reglas. Cambiar el catálogo no reescribe el empaque ni el costo de lotes y comprobantes anteriores.

## Precios, crédito y correcciones

- Cada presentación utiliza dos precios independientes: promocional USD efectivo y normal de referencia para VES. Ni el costo de compra ni el precio de caja determinan automáticamente los demás. El propietario decide cuándo conservar o modificar la lista en una recepción.
- El crédito puede comenzar sin abono; fecha pactada y recordatorio se registran por separado. No existe aprobación comercial artificial ni un límite de crédito inventado. Las condiciones concretas con cada cliente las decide el negocio.
- Los abonos se aplican explícitamente a los comprobantes elegidos. No hay asignación automática de excesos ni un saldo manual editable.
- Las anulaciones y reversas conservan historia. Faltan reglas acordadas para devoluciones parciales, cambios de mercancía y condiciones particulares; no deben simularse mediante ajustes sin explicación.

## Dependencias externas que no deben darse por resueltas

| Tema                      | Estado y próximo paso                                                                                                                                                                                                                                                                                       |
| ------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| BCV y cobros VES          | No hay un flujo operativo acreditado de incorporación de tasa oficial vigente. VES sigue bloqueado. Verificar fuente, vigencia y evidencia; cualquier incorporación manual excepcional requiere validación expresa del propietario antes de activarse. No solicitar ni inventar una tasa por chat.          |
| Comprobantes y fiscalidad | Los PDF son documentos comerciales internos, no facturas fiscales SENIAT. Revisar el texto oficial, vigencia y aplicación de la Providencia SNAT/2026/00093 con asesor contable antes de atribuir cumplimiento fiscal. Una referencia a esa providencia en el encargo no sustituye su verificación oficial. |
| Tablet Android            | Falta la prueba física de permiso, entrega push, revocación y apertura autenticada. Configurar el servidor no acredita recepción por el dispositivo.                                                                                                                                                        |
| WhatsApp corporativo      | Confirmar en la tablet que el botón abre el perfil corporativo y el destinatario correcto. Enviar permanece como acción manual del operador; no se realizan mensajes automáticos de ensayo a clientes.                                                                                                      |
| Apertura de producción    | La habilitación depende de los controles y autorizaciones registrados en la entrega de fase 4, incluido respaldo externo restaurable y cambio de ruta autorizado. Este documento no declara producción publicada ni sustituye esos controles.                                                               |

Las confirmaciones de producto se guardan en el catálogo real por los propietarios. Las comprobaciones de infraestructura, respaldo, moneda y dispositivos deben conservar evidencia y fecha propias, separadas de los ensayos sintéticos de QA.
