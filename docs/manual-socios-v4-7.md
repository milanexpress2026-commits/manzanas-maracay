# Manzanas Maracay · Manual para socios

Guía del candidato V4.7. Su publicación está pendiente de validación y autorización operativa final; este documento no afirma que V4.7 esté disponible en la URL del negocio. Cuando se confirme la publicación, entra por [Manzanas Maracay](https://manzanas.ganamosclub.net) con el acceso privado de los dueños. En un dispositivo del negocio puedes marcar **Mantener sesión activa** durante 30 días y cerrar sesión cuando lo necesites.

## 1. Recibir mercancía

Abre **Recibir mercancía**, busca el producto y comprueba variedad, calibre y presentación. Escribe **Cajas recibidas**; en alimentos, confirma la **Unidad comercial** real y las unidades recibidas. Usa **Otra fruta** para añadir líneas. Proveedor, documento externo y fecha manual son opcionales. No se pide costo de compra ni lista de precios.

Pulsa **Revisar y guardar**, comprueba las cantidades y luego **Guardar recepción**. Espera **Recepción guardada** y su folio. Recibir manzana tradicional no equivale a recibir manzana **A granel**. Si el empaque real es excepcional, confírmalo antes de guardar.

## 2. Vender con el precio de esa venta

En **Nueva venta**, busca o crea el cliente, elige el producto disponible y su presentación. Escribe la cantidad y **Precio por unidad (USD)** en cada línea. El precio se escribe para esa venta; no configura una lista general ni cambia ventas anteriores.

Elige **Acuerdo de cobro**: **Promoción / divisa** o **Regular / BCV**. El acuerdo queda fijado aunque se cobre después. **Contado** cobra el total; **Crédito** permite dejar deuda sin abono inicial. Si hay abono, indica lo realmente recibido. La fecha pactada y el recordatorio son independientes. Revisa el resumen y confirma una sola vez. Espera el folio de la venta guardada.

## 3. Elegir cómo cobrar o abonar

| Método | Cómo se aplica |
| --- | --- |
| **Efectivo USD** | Los USD recibidos pagan el mismo importe de deuda USD. Sirve para ambos acuerdos. |
| **USDT** | Cada USDT recibido paga un USD. La equivalencia en Bs. es informativa; no registra bolívares recibidos. Se puede cobrar USDT aunque esa referencia no esté disponible. |
| **Bolívares a tasa BCV** | Para **Regular / BCV** y acuerdos históricos compatibles. Se guarda el importe real en Bs. y la tasa oficial vigente usada. |
| **Bolívares a tasa Binance/USDT compra** | Para **Promoción / divisa**. Se usa la referencia de compra Binance P2P vigente; el precio USD acordado permanece igual. |

Una tasa vencida o no disponible bloquea el nuevo cobro en Bs. correspondiente. No escribas una tasa inventada. USD y USDT siguen siendo opciones si el cliente paga realmente así.

En **Cobranza**, elige las facturas concretas y revisa cuánto se aplica a cada una. Para Bs., separa facturas con acuerdos incompatibles. Un abono no cambia los precios pactados ni se reparte automáticamente entre otras deudas.

## 4. Imprimir la nota de entrega

Después de guardar la venta, pulsa **Imprimir nota**. La aplicación prepara el PDF; en el visor, elige **Imprimir** y la impresora HP. La nota usa **Carta**, vertical. Si hace falta A4, abre **Comprobante y tamaño de papel** antes de generar la nota.

Si el navegador bloquea otra pestaña, usa **Ver nota en esta pestaña**. También están **Ver nota de entrega** y **Descargar nota**. Abre el archivo descargado con el visor PDF del dispositivo si Chrome no permite imprimirlo directamente. Comprueba folio, cliente, productos, cantidades, total y todas las páginas en la vista previa. Sigue la [guía HP de una hoja](guia-impresion-hp-v4-7.pdf).

## 5. Reimprimir o consultar una venta

En **Ventas**, abre el folio guardado y vuelve a **Imprimir nota** o **Descargar nota**. Reimprimir no registra otra venta, no cobra de nuevo ni vuelve a descontar mercancía. El **comprobante de venta** es otro documento, disponible en **Comprobante y tamaño de papel**.

Los saldos actuales al imprimir se identifican en el PDF; los datos originales de la venta se conservan. Una venta anulada se identifica como tal y no autoriza entregar mercancía. La aplicación no certifica que la impresora haya terminado el trabajo.

## 6. Si falla Internet, la sesión o la HP

- **No llegó la respuesta al guardar:** vuelve con el mismo dispositivo, navegador y acceso. Usa **Reintentar misma recepción**, **Recuperar venta pendiente** o **Recuperar abono pendiente**, según el caso. Revisa y confirma la operación recuperada. No crees otra venta ni otro abono para compensar una pantalla sin respuesta. No borres los datos del navegador mientras haya operaciones pendientes.
- **Otra pestaña está trabajando:** vuelve a ella y espera su resultado. No abras una operación paralela para saltarte el aviso.
- **Sesión vencida al abrir un PDF:** usa **Iniciar sesión y volver a esta venta**. El documento falló, pero la venta permanece guardada. Recupera el acceso y vuelve a abrirla.
- **No hay conexión:** conserva lo pendiente y espera a recuperar Internet. La aplicación no confirma ventas ni abonos sin conexión. Si el dispositivo se pierde o sus datos se borran, revisa el historial con apoyo antes de registrar de nuevo.
- **HP apagada, sin papel o sin conexión:** descarga el PDF, comprueba que abre y consérvalo para imprimir después. Si usarás Wi-Fi Direct y cambiarás de red, descarga antes; esa conexión puede dejar la tablet sin Internet. No vuelvas a vender para conseguir otra copia.

**Son documentos comerciales, no facturas fiscales homologadas.** WhatsApp solo prepara el mensaje: tú decides si lo envías.

**Validación humana pendiente:** probar la tablet real y la HP Smart Tank 215 con una nota protegida de una página y otra de varias páginas. La impresión previa de una imagen ordinaria no acredita ese recorrido. El guion y el registro están en la [guía de impresión](guia-impresion-hp-v4-7.md).
