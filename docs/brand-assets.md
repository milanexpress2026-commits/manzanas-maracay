# Logo oficial y activos de marca

El propietario entregó el logo oficial de Manzanas Maracay en este proyecto el **4 de noviembre de 2026**. Es el archivo PNG cuadrado de 1254 × 1254 px, con transparencia, que contiene la manzana sobre el tractor, las frutas y la inscripción «Manzanas Maracay · Frutas importadas».

## Archivos

- [Original intacto](../apps/web/public/brand/logo-manzanas-maracay.png): fuente de referencia para todas las variantes.
- [Versión web](../apps/web/public/brand/logo-manzanas-maracay.webp): 512 × 512 px, 92.574 bytes, con transparencia, utilizada por la interfaz y la página sin conexión.
- `apps/web/public/icons/`: PNG de 192 y 512 px, favicon de 64 px y Apple Touch de 180 px. El icono adaptable de 512 px tiene la marca completa dentro de un área central de 280 px para protegerla del recorte circular del sistema.

Las variantes se generaron mediante escalado proporcional con Sharp 0.35.5, disponible entre las dependencias del proyecto, sin reconstruir el dibujo. El SHA-256 del original coincide con el adjunto del propietario: `1ACB862023ED023AD593F55255502CCDEBC3895781A837E2DF3EE217566546D1`.

Las cuatro imágenes en `docs/referencias` siguen siendo modelos conceptuales de pantallas. No sustituyen el archivo oficial ni deben usarse para reconstruirlo.

## Uso

Conservar proporción, colores, lettering y composición completa. Ajustar dimensiones y compresión para cada superficie sin estirar, recortar partes, recolorear ni generar un nuevo dibujo. Mantener espacio alrededor para que los bordes del contenedor o las máscaras de iconos no corten la marca. Usar un nombre accesible cuando la imagen identifique el negocio; evitar duplicarlo si el texto adyacente ya cumple esa función.

El original no se sobrescribe al regenerar variantes. La incorporación del logo no cambia el alcance funcional de la fase 1.
