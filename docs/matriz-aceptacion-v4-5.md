## Compatibilidad que se conserva

- Recepciones anteriores con costos explícitos y sus claves idempotentes siguen legibles y reproducibles. Las pruebas nuevas no reinterpretan esos costos como cero.
- Las aserciones históricas de costo se contrastan en la base aislada; la API operativa, la interfaz y los PDF ya no deben revelar costos ni utilidades.
- Los casos que exigían costo o lista para una operación nueva se adaptan a la regla V4.5, conservando sus verificaciones de inventario, auditoría, concurrencia y recuperación.
- Los registros de precio históricos permanecen sin cambios; una venta manual no crea ni actualiza listas.

## Límites de la evidencia

Las capturas y el vídeo representan Chromium con tamaños de pantalla emulados. No prueban una tablet física, un teclado Android real ni una prueba con personas ajenas al desarrollo. Esas verificaciones se indicarán como pendientes mientras no existan evidencias. La URL real y el estado del VPS se documentarán por separado después del proceso autorizado de publicación.
