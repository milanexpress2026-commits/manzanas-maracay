# Manzanas Maracay · Guía para los socios

## Cómo recibir cajas

1. Abre **Recibir mercancía**, busca el producto y elige variedad y calibre. Usa **Otra fruta** para agregar más productos.
2. Revisa la presentación y escribe **Cajas recibidas**. Para alimentos, indica la **Unidad comercial** real y las **Unidades recibidas**. Puedes dejar el proveedor sin indicar.
3. Pulsa **Revisar y guardar** y luego **Guardar recepción**. Se asignan número y fecha. Si falta la respuesta, usa **Reintentar misma recepción**; el borrador se conserva al cerrar y volver.

Las manzanas tradicionales y las de **A granel** son productos distintos. **PC** es un calibre válido de granel. Si el empaque es excepcional, revísalo antes de guardar; los lotes anteriores se conservan.

## Cómo vender y escribir precio

1. Abre **Nueva venta**, busca o crea el cliente y elige la mercancía disponible.
2. Escribe **Cantidad** y **Precio por unidad (USD)** en cada producto. Revisa el total.
3. En **Acuerdo de cobro**, elige **Promoción / divisa** para futuros Bs. a Binance compra, o **Regular / BCV** para futuros Bs. a BCV. El precio y el acuerdo quedan guardados.
4. Elige **Contado** para cobrar todo o **Crédito** para dejar saldo. En crédito puedes marcar **Registrar un abono ahora** y elegir cuándo cobrar: 7 días, 15 días o calendario.
5. Revisa y confirma. Abre **Nota de entrega · Abrir para imprimir** para imprimir desde el PDF y seleccionar la HP Smart Tank 215. Reimprimir no vuelve a descontar mercancía.

## Cómo cobrar USD, USDT o bolívares

| Método de cobro | Qué recibe el negocio |
| --- | --- |
| **Efectivo USD** | Dólares que se aplican directamente al saldo USD. |
| **USDT** | Cada USDT cancela un USD. Los Bs. mostrados son solo una referencia. Puedes cobrar aunque esa equivalencia no esté disponible. |
| **Bolívares a tasa BCV** | Bs. con la tasa oficial vigente, para el acuerdo **Regular / BCV**. |
| **Bolívares a tasa Binance/USDT compra** | Bs. con la referencia de compra vigente, para **Promoción / divisa**. El precio USD pactado no cambia. |

**USD y USDT pueden pagar cualquiera de los dos acuerdos.** En **Cobranza**, elige los comprobantes y revisa cuánto aplicar a cada uno. Al pagar todo, salen de pendientes y conservan el historial. Una tasa vencida bloquea únicamente el nuevo cobro en Bs. que la necesita.

**WhatsApp** abre el chat con el mensaje preparado; tú decides si lo envías. **Los PDF son documentos comerciales, no facturas fiscales homologadas.**
